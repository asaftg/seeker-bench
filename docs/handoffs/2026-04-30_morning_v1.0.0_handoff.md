## Recording capabilities at V1.0

When the operator presses REC, the system writes (per
`docs/PHASE_3_RECORDER_FIELDS.md` and verified end-to-end with the
recording smoke test):

```
recordings/<name>.jsonl       Bus stream (eo, thermal, radar, fusion,
                              gimbal, events, session/header)
recordings/<name>.meta.yaml   Schema version, mode, profile, awr_cfg
                              path + sha256, frame_dims, pmm knobs,
                              capture (host_ip, socket_recv_buffer)
recordings/<name>_radar.bin   Raw ADC byte stream  (aa mode only)
recordings/<name>_radar.csv   Per-packet seek index for the .bin
                              (ts_host_ns, byte_offset, payload_len,
                               seq_num, chunk_offset)
```

This is enough to reconstruct any field session offline. The four
"best-effort" fields the recorder agent skipped silently
(`awr_firmware.*`, `dca.fpga_version`, `capture.host_nic`,
`capture.mtu`) are documented as open in `RELEASE_NOTES_v1.0.0.md`
— operators can fill them by hand or run `DCA1000EVM_CLI_Control fpga`
manually.

## What's blocking real-world usefulness (not blocking V1.0 release)

These are documented in `RELEASE_NOTES_v1.0.0.md` and `docs/NEXT.md`,
copied here for the morning view:

### P0 — Field test will produce noisy data without these
1. **PMM detector tuning** (`radar_dca/pmm_detector.py`): mask
   range bins 0..2 (TX leakage), subtract slow-time mean per range
   bin (clutter), raise threshold 6→12 dB, add absolute-power gate.
   Without this the AA mode fires on every range bin and blade-freq
   sticks at 52.7 Hz band-edge artifact. Recipe in

   park a target in the FOV and drag the sliders until the projected
   `RADAR_TARGET` bbox sits on the EO bbox of the same target. Then
   class-promotion will fire.

## If the PyInstaller build failed

Check `docs/handoffs/_BUILD_STATUS_v1.0.0.txt` (autonomous run log)
and `/tmp/v1.0.0_build.log`. Common failures:
- Missing optional dep (PyInstaller's analysis can flag `ultralytics`
  or `torch` extras). Re-run `python -m pip install -r requirements.txt`.
- Stale `build/` cache. `rm -rf build dist` and re-run `build_exe.bat`.
- Console tab open (build/seeker_bench is locked). Close any open
  exe / Explorer windows.

The tag is independent of the dist artifact — V1.0 is still tagged
even if PyInstaller failed locally. The Jetson agent doesn't use
PyInstaller anyway (Linux/JetPack uses a venv + systemd unit per
README §"Edge device deployment").
