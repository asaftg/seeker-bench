Distribution instructions
-------------------------
The dist is a folder distribution. To deploy on a new Windows
laptop:

  1. Copy the entire dist/seeker_bench/ folder (~5 GB).
  2. Double-click seeker_bench.exe.
  3. The browser opens to http://localhost:8080.

The .exe keeps a console window open by default so crashes are
visible. Set console=False in seeker_bench.spec once stable for
production.

Models can be hot-swapped without rebuilding: drop new .pt files
into dist/seeker_bench/_internal/models/ and restart the .exe.

Jetson port note
----------------
This dist is Windows-x64 only. The Jetson Xavier AGX port does NOT
use PyInstaller — it builds from source on-device per the README §
"Edge device deployment" (venv + systemd). The v1.0.0 git tag is
the immutable starting point for that port.

Smoke check (post-build, NOT run by autonomous script)
------------------------------------------------------
The autonomous run did NOT execute the .exe — that would open the
GUI on localhost:8080 and try to enumerate USB sensors, which
risks colliding with anything else live on the bench. The
operator should manually confirm:

  cd dist\seeker_bench
  seeker_bench.exe
  → browser opens to http://localhost:8080
  → THERMAL pill turns green (or red if camera not plugged)

If it crashes, the console window keeps the traceback visible.
First place to check: the Boson camera detection path
(thermal/boson_capture.py) — it's the only module that can fail
to even import on a clean Windows machine if DSHOW behaves
differently.
